# ДЗ 13.2: Channel Ping-Pong

## Цель
Научиться синхронизировать горутины через каналы, понять блокирующую природу операций с каналами.

## Что нужно сделать

1. Реализовать функцию `player`, которая принимает "мяч" из одного канала и отправляет в другой
2. Реализовать функцию `playGame`, которая запускает игру ping-pong на заданное количество ударов
3. Понять, как каналы синхронизируют работу горутин

## Сигнатуры

```go
// Ball представляет мяч в игре
type Ball struct {
    Hits int // Количество ударов
}

// player представляет игрока
// Получает мяч из inbox, увеличивает счётчик ударов,
// выводит информацию и отправляет в outbox
func player(name string, inbox <-chan Ball, outbox chan<- Ball)

// playGame запускает игру ping-pong
// maxHits - максимальное количество ударов
func playGame(maxHits int)
```

## Теория: направленные каналы

В Go можно ограничить направление канала:

```go
chan T      // двунаправленный канал
chan<- T    // канал только для отправки (send-only)
<-chan T    // канал только для получения (receive-only)
```

Это помогает предотвратить ошибки и делает намерения кода яснее.

## Пример использования

```go
func main() {
    playGame(6)
}
```

## Ожидаемый вывод

```

```

## Схема работы

```
     ping канал           pong канал
         |                    |
         v                    v
[Ping] ----> inbox  outbox ----> [Pong]
         <----       <----
              outbox       inbox
```

1. Начальный мяч отправляется в канал ping
2. Игрок Ping получает мяч, увеличивает счётчик, отправляет в канал pong
3. Игрок Pong получает мяч, увеличивает счётчик, отправляет обратно в канал ping
4. Повторяется до достижения maxHits

## Подсказки

- Создай два канала: `pingCh` и `pongCh`
- Игрок Ping читает из `pingCh`, пишет в `pongCh`
- Игрок Pong читает из `pongCh`, пишет в `pingCh`
- Используй `for` цикл с `range` для чтения из канала
- Закрывай канал, когда достигнуто максимальное количество ударов
- Проверяй `ball.Hits >= maxHits` перед отправкой

## Критерии выполнения

- [ ] Ball корректно передаётся между горутинами
- [ ] Счётчик ударов увеличивается при каждой передаче
- [ ] Вывод показывает чередование Ping и Pong
- [ ] Игра корректно завершается после maxHits ударов
- [ ] Используются направленные типы каналов (chan<- и <-chan)
- [ ] Нет deadlock'ов и panic'ов
