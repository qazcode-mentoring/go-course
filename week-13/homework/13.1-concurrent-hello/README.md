# ДЗ 13.1: Concurrent Hello

## Цель
Научиться запускать горутины и понять, что порядок их выполнения недетерминирован.

## Что нужно сделать

1. Реализовать функцию `sayHello`, которая выводит приветствие с именем
2. Реализовать функцию `runConcurrent`, которая запускает несколько горутин
3. Понять и объяснить (в комментарии), почему порядок вывода может меняться

## Сигнатуры

```go
// sayHello выводит приветствие с номером и именем
// Формат: "Привет #N от NAME!"
func sayHello(id int, name string, wg *sync.WaitGroup)

// runConcurrent запускает горутины для каждого имени из списка
// и ждёт их завершения
func runConcurrent(names []string)
```

## Теория: WaitGroup

`sync.WaitGroup` используется для ожидания завершения группы горутин:

```go
var wg sync.WaitGroup

wg.Add(1)      // Увеличить счётчик на 1
go func() {
    defer wg.Done()  // Уменьшить счётчик на 1 при завершении
    // ... работа ...
}()

wg.Wait()      // Ждать пока счётчик не станет 0
```

## Пример использования

```go
func main() {
    names := []string{"Алиса", "Боб", "Чарли", "Дэйв", "Ева"}

    fmt.Println("=== Запуск 1 ===")
    runConcurrent(names)

    fmt.Println("\n=== Запуск 2 ===")
    runConcurrent(names)

    fmt.Println("\n=== Запуск 3 ===")
    runConcurrent(names)
}
```

## Ожидаемый вывод (порядок может отличаться!)

```
=== Запуск 1 ===
Привет #2 от Чарли!
Привет #0 от Алиса!
Привет #4 от Ева!
Привет #1 от Боб!
Привет #3 от Дэйв!

=== Запуск 2 ===
Привет #0 от Алиса!
Привет #3 от Дэйв!
Привет #1 от Боб!
Привет #2 от Чарли!
Привет #4 от Ева!

=== Запуск 3 ===
Привет #1 от Боб!
Привет #0 от Алиса!
Привет #2 от Чарли!
Привет #4 от Ева!
Привет #3 от Дэйв!
```

**Обрати внимание:** порядок вывода разный при каждом запуске!

## Подсказки

- Используй `sync.WaitGroup` для ожидания завершения горутин
- Не забудь вызвать `wg.Add(1)` перед каждой горутиной
- Используй `defer wg.Done()` в начале горутины
- `wg.Wait()` блокирует выполнение до завершения всех горутин

## Критерии выполнения

- [ ] Функция `sayHello` выводит приветствие в нужном формате
- [ ] Функция `runConcurrent` запускает горутины для каждого имени
- [ ] Используется `sync.WaitGroup` для синхронизации
- [ ] Программа корректно завершается (не завершается раньше горутин)
- [ ] В комментарии объяснено, почему порядок вывода недетерминирован
