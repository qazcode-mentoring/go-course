1. Как тип реализует интерфейс в Go?
В го тип неявно реализует интерфейс если все реализованные методы объявлены в этом интерфейсе,
 не нужно писать implements как на java.

2. Что такое пустой интерфейс (interface{} / any)?
Пустой интерфейс - интерфейс который не содержит методы. Поэтому он может принимать любые типы.

3. Чем type assertion отличается от type switch?
v, ok := x.(type) - это безопасное использование type assertion. type switch - мы просто используем switch-case.
type assertion - эффективен когда мы проверяем конкретно на один типа из interface{}. type switch эффективен когда
типов несколько.

4. Что произойдёт при type assertion к неправильному типу?

var x any = "hello"

n := x.(int)
fmt.Println(n)

Вот так будет паника

var x any = "hello"

	n, ok := x.(int)
	if !ok {
		fmt.Println("fail")
		return
	}
	fmt.Println(n)
а это безопасное использование type assertion


5. Может ли значение nil удовлетворять интерфейсу?
Да, если сам интерфейс не содержит конкретный тип. Если интерфейс равен указателю который равен nil, интерфейс не будет nil
