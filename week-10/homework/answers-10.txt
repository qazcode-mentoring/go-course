Как тип реализует интерфейс в Go?
Тип реализует интерфейс неявно, если он реализует все методы этого интерфейса.
В Go не используется ключевое слово implements

Что такое пустой интерфейс (interface{} / any)?
Это интерфейс без методов, который может хранить любой тип

Чем type assertion отличается от type switch?
Type assertion используется для приведения интерфейса к конкретному типу.
Switch позволяет проверить сразу несколько типов

Что произойдёт при type assertion к неправильному типу?
Если нет проверки, при несовпадении типов ---> panic

Может ли значение nil удовлетворять интерфейсу?
Да, интерфейса может хранить в себе nil значение
