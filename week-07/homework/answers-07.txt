Что вернёт обращение к несуществующему ключу map?
Будет возвращено нулевое значения для типа значения карты

Как проверить, существует ли ключ в map?
Можно использовать двоейное присваивание, так как map[key] позволяет получить два значения
- значение ключа и bool значение на существование

Можно ли итерировать по map в определённом порядке?
Нет, порядок обхода map не определён и может отличаться при каждом запуске программы.
Порядок итерации по map специально рандомизирован.

Что произойдёт при записи в nil map?
При записи в nil map в Go произойдёт паника времени выполнения (runtime panic)

Можно ли использовать слайс как ключ map? Почему?
Нельзя, потому что слайс является ссылочным типом который может изменяться и обращатьс по ключу будет затруднительно
Ключи должны быть сравнимыми, а слайсы таким не являются.
