1. В чём разница между `json.Marshal` и `json.NewEncoder().Encode()`? Когда следует использовать каждый из них?
json.Marshal преобразует json в структуру и возвращает byte[]. json.NewEncoder().Encode() пишет сразу в файл не возвращая byte[]
json.Marshal лучше всего использовать тогда когда нужно сохранить json в переменную, json.NewEncoder().Encode() тогда когда нужно сразу закинуть
в поток

2. Что делает тег `omitempty` и для каких типов он работает? Приведи пример, когда его использование может привести к неожиданному поведению.
Если какое то поле omitempty, то это поле не включается в json. Неожиданное поведение происходит для bool, когда значение bool должен быть false,
а в json попадает ничего. В такие моменты используются указатели.

3. Почему при десериализации JSON числа всегда становятся `float64`, если использовать `map[string]any`? Как получить целое число?
json не определяет какой это тип (int или float), для json это number. Поэтому когда мы делаем десерилизацию, мы получаем float64.
Чтобы получить целое число, нужно создать структуру с типом int, и использовать эту структуру при десериализации.

4. Объясни разницу между `os.ReadFile` и использованием `bufio.Scanner`. Когда следует использовать каждый подход?
Разница в том что os.ReadFile читает файл целиком, и возвращает []byte, а bufio.Scanner читает файл построчно и работает через буфер,
то есть не напрямую. os.ReadFile лучше использовать когда файл небольшой, и после чтения нужно что то поделать с []byte.
bufio.Scanner использовать когда файл большой, не выгружать все сразу в память.

5. Зачем нужен вызов `defer file.Close()` и что произойдёт, если его забыть? Что такое file descriptor leak?
Когда мы читаем файл, ОС выделяет некую память для файла. defer file.Close() нужен чтобы гарантированно закрыть файл, и освободить память.
file descriptor leak происходит тогда, когда мы забываем закрыть файл и если открыть много файлов и забыть закрыть, в итоге получим сообщение
что открыто много файлов.
