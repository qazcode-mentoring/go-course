В чём разница между json.Marshal и json.NewEncoder().Encode()? Когда следует использовать каждый из них?
Marshal преобразует go структуру в json формат, он записывает весь JSON целиком в оперативную память
json.NewEncoder().Encode() кодирует структуру и тут же отправляет её в «трубу» (Writer).

Что делает тег omitempty и для каких типов он работает? Приведи пример, когда его использование может привести к неожиданному поведению.
omitempty срабатывает если поле имеет нулевое значение и в json текст поле просто не добавляется
Срабатывает, если если поле имеет свое нулевое значение (string - "", float - 0.0, и тд)
К неожиданному поведению может привести для типо boolean потому что его нулевое значение - false, а это тоже данные
Такое поле может просто "исчезнуть" и если json передавали с бэка на фронт, то фронт поля этого не получит

Почему при десериализации JSON числа всегда становятся float64, если использовать map[string]any? Как получить целое число?
JSON не разделяет числа на целые и дробные для него это просто «числа». Поэтому по умолчанию парсер Go переводит их в float64

Объясни разницу между os.ReadFile и использованием bufio.Scanner. Когда следует использовать каждый подход?
os.ReadFile считывает весь файл целиком в оперативную память за один раз и возвращает его в виде одного большого слайса байтов ([]byte)
bufio.Scanner читает файл по кусочкам (по строчно)

Зачем нужен вызов defer file.Close() и что произойдёт, если его забыть? Что такое file descriptor leak?
ОС предоставляет лимит ячеек и если открывать файлы и не закрывать, то ячейки могут закончится и придет ошибка «too many open files»
Иногда данные сначала пишутся в буфер (временную память), и только при закрытии файла окончательно переносятся на диск. Если не закрыть файл, часть данных может просто пропасть.
File Descriptor Leak (утечка дескрипторов файлов) это как раз то состояние, когда программа «теряет» контроль над открытыми ресурсами.
