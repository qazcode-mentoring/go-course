# ДЗ 16.1: Первые тесты

## Цель
Научиться писать базовые тесты в Go: создавать Test* функции, использовать методы `t.Error`, `t.Errorf`, `t.Fatal`, `t.Fatalf` и запускать тесты через `go test`.

## Что нужно сделать

В файле `main.go` реализованы функции для работы со строками. Твоя задача — написать тесты в файле `main_test.go`.

### Функции для тестирования

1. **Reverse(s string) string** — переворачивает строку
2. **IsPalindrome(s string) bool** — проверяет, является ли строка палиндромом
3. **CountWords(s string) int** — считает количество слов в строке
4. **Truncate(s string, maxLen int) string** — обрезает строку до maxLen символов, добавляя "..." если обрезали

### Тесты, которые нужно написать

1. `TestReverse` — проверь несколько случаев:
   - Обычная строка ("hello" -> "olleh")
   - Пустая строка
   - Строка из одного символа
   - Строка с пробелами

2. `TestIsPalindrome` — проверь:
   - Палиндромы ("radar", "level")
   - Не-палиндромы ("hello")
   - Пустая строка (считается палиндромом)
   - Один символ

3. `TestCountWords` — проверь:
   - Обычное предложение
   - Пустая строка (0 слов)
   - Строка с множественными пробелами
   - Одно слово

4. `TestTruncate` — проверь:
   - Строка короче maxLen (не обрезается)
   - Строка длиннее maxLen (обрезается с "...")
   - maxLen <= 3 (крайний случай)

## Пример теста

```go
func TestReverse(t *testing.T) {
    result := Reverse("hello")
    expected := "olleh"

    if result != expected {
        t.Errorf("Reverse(%q) = %q; want %q", "hello", result, expected)
    }
}
```

## Запуск тестов

```bash
# Запустить все тесты
go test

# Запустить с подробным выводом
go test -v

# Запустить конкретный тест
go test -run TestReverse

# Запустить тесты с покрытием
go test -cover
```

## Подсказки

- Используй `t.Errorf` для информативных сообщений об ошибках
- Формат `got X, want Y` — стандартный в Go
- `t.Fatal` используй, когда продолжать тест бессмысленно (например, если функция вернула nil вместо объекта)
- Каждый Test* должен тестировать одну функцию, но может содержать несколько проверок

- [ ] Написан `TestIsPalindrome` с минимум 4 проверками
- [ ] Написан `TestCountWords` с минимум 3 проверками
- [ ] Написан `TestTruncate` с минимум 3 проверками
- [ ] Все тесты проходят (`go test` без ошибок)
