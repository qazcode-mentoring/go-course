Что такое функция первого класса (first-class function)?
Это функции назначенные переменным, эти функции можно передавать в качестве аргументов
другим функциям и возрвращать из других функций.

Что такое замыкание и какие переменные оно захватывает?
Замыкание - это функция внутри функции.
Оно состоит из:
    - внешней функции
    - переменные среды (переменные в внешней функции)
    - внутренней функции
При этом внутренняя функция может использовать переменные извне.

Чем отличается передача функции как значения от вызова функции?
Передача функции как значения означает, что функция передаётся в качестве аргумента и может быть вызвана в вызываемой функции.
Вызов функции означает, что тело функции выполнено и оно возвращает значение.

Что произойдёт если замыкание изменяет захваченную переменную?
Если внутренняя функци изменит перменную во внешней функции, то изменение сохраняется и при повторном вызове
переменная останется измененной

Как создать функцию, которая возвращает другую функцию?
Для внешней функции сперва нужно указать, что оно будет возрващать другую функцию:
    func Counter() func() int {}
После, внутри функции нужо вернуть функцию замыкания
    return func() int {}
